# Internship-Technosignia — Java Internship Tasks

This repository contains Java practice programs for the Technosignia Java Full Stack Development internship tasks.

## Day 2 — Java Fundamentals
- `Day2/BasicCalculator.java` — arithmetic operations and input validation.
- `Day2/NumberPrograms.java` — even/odd, prime, factorial, and palindrome checks.
- `Day2/GradeCalculator.java` — total, percentage, and grade for five subjects.
- `Day2/ArrayStatistics.java` — array sum, average, minimum, and maximum.
- `Day2/README.md` — instructions for running Day 2 programs.

## Day 3 — Object-Oriented Programming
- `Day3/Student.java` — Student class with private fields, constructor, getters/setters and display method.
- `Day3/Employee.java` — Employee class demonstrating encapsulation and constructors.
- `Day3/StudentManagementApp.java` — Console app that creates and displays student records.

## Day 4 — Advanced Java
- `Day4/StudentRecordsApp.java` — Student records using `ArrayList`, `HashMap`, searching by ID/name, sorting by name/marks, exception handling, file save/load, and Streams.

## Day 5 — Git and GitHub
- `Day5/GitAndGitHub.md` — repository, staging, commit, push/pull, clone, and branch command notes.

## Run the programs
Install JDK 8 or later. For example, from the Day 2 folder:

```bash
cd Day2
javac BasicCalculator.java
java BasicCalculator
```

Other programs can be compiled and run using their matching class names. For Day 3, compile `Student.java`, `Employee.java`, and `StudentManagementApp.java` together before running `StudentManagementApp`.

**Note:** The Day 2 task sheet was not available in this chat, so Day 2 contains common Java fundamentals practice programs. Compare them with your official Day 2 instructions if your internship specifies a different list. Day 1 programs have not been added because their task sheet was not available.
