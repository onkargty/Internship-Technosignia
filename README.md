# Internship-Technosignia — Java Internship Tasks

This repository contains Java practice programs for the Technosignia Java Full Stack Development internship tasks.

## Day 3 — Object-Oriented Programming
- `Day3/Student.java` — Student class with private fields, constructor, getters/setters and display method.
- `Day3/Employee.java` — Employee class demonstrating encapsulation and constructors.
- `Day3/StudentManagementApp.java` — Console app that creates and displays student records.

## Day 4 — Advanced Java
- `Day4/StudentRecordsApp.java` — Student records using `ArrayList`, `HashMap`, searching by ID/name, sorting by name/marks, exception handling, file save/load, and Streams.

## Day 5 — Git and GitHub
- Repository and version-control practice is represented by this organized repository and README.

## Run the programs
Install JDK 8 or later. Open a terminal in the relevant folder and compile/run the program. For example:

```bash
cd Day3
javac Student.java Employee.java StudentManagementApp.java
java StudentManagementApp
```

For Day 4:

```bash
cd Day4
javac StudentRecordsApp.java
java StudentRecordsApp
```
