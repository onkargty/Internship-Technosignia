# Day 5 — Git and GitHub

## Topics covered
- Create a GitHub repository
- Initialize and configure Git
- Stage and commit files
- Push and pull changes
- Clone a repository
- Create and switch branches
- Document a project with README.md

## Common commands

```bash
git init
git config --global user.name "Your Name"
git config --global user.email "you@example.com"
git add .
git commit -m "Add Java internship tasks"
git branch -M main
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
git pull origin main
git clone https://github.com/USERNAME/REPOSITORY.git
git switch -c feature-branch
```

Replace the example name, email, username, and repository URL with your own details. Do not put passwords or access tokens in source files.
