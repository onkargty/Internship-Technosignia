# Day 2 — Java Fundamentals

These practice programs cover common Java fundamentals: input/output, variables, operators, conditionals, loops, methods, and arrays.

## Programs
- BasicCalculator.java — arithmetic using a switch statement and input validation.
- NumberPrograms.java — even/odd, prime check, factorial, and palindrome check.
- GradeCalculator.java — calculates total, percentage, and grade for five subjects.
- ArrayStatistics.java — reads an integer array and calculates sum, average, minimum, and maximum.

## Run
Install JDK 8 or later. From this folder, compile and run any one program:

    javac BasicCalculator.java
    java BasicCalculator

Replace BasicCalculator with NumberPrograms, GradeCalculator, or ArrayStatistics to run another program.
