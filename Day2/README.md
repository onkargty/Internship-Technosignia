# Day 2 — Java Fundamentals

These practice programs cover input/output, variables, operators, conditionals, loops, methods, and arrays.

## Requested number practice programs

Each of the following is available as its own Java file:
- `EvenOdd.java` — checks whether a number is even or odd.
- `LargestOfThree.java` — finds the largest of three integers.
- `Factorial.java` — calculates factorial for integers from 0 to 20.
- `PrimeNumber.java` — checks whether a number is prime.
- `ReverseNumber.java` — reverses an integer.
- `MultiplicationTable.java` — prints a multiplication table from 1 to 10.

You can also use `NumberPrograms.java`, which provides a menu for these tasks plus a palindrome check.

## Other programs
- `BasicCalculator.java` — arithmetic using a switch statement and input validation.
- `GradeCalculator.java` — calculates total, percentage, and grade for five subjects.
- `ArrayStatistics.java` — calculates sum, average, minimum, and maximum for an integer array.

## Run
Install JDK 8 or later. From this folder, compile and run the program you want. For example:

    javac EvenOdd.java
    java EvenOdd

Replace `EvenOdd` with `LargestOfThree`, `Factorial`, `PrimeNumber`, `ReverseNumber`, `MultiplicationTable`, or `NumberPrograms` to run another number-practice program.

Note: These are standard Java fundamentals exercises. The Day 2 task sheet was not available in the chat, so check these against the exact task list if your internship specifies different programs.
