# Day 2 — Java Fundamentals

These practice programs cover input/output, variables, operators, conditionals, loops, methods, and arrays.

## Programs
- `BasicCalculator.java` — arithmetic using a switch statement and input validation.
- `NumberPrograms.java` — menu-driven practice for:
  - Check whether a number is even or odd.
  - Find the largest of three numbers.
  - Calculate factorial.
  - Check whether a number is prime.
  - Reverse a number.
  - Print a multiplication table (1 to 10).
  - Check whether a number is a palindrome (extra practice).
- `GradeCalculator.java` — calculates total, percentage, and grade for five subjects.
- `ArrayStatistics.java` — reads an integer array and calculates sum, average, minimum, and maximum.

## Run
Install JDK 8 or later. From this folder, compile and run:

    javac NumberPrograms.java
    java NumberPrograms

Choose an option from the menu and follow the prompts. To run another program, replace `NumberPrograms` with `BasicCalculator`, `GradeCalculator`, or `ArrayStatistics`.
